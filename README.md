
# Balaji R — Cybersecurity Portfolio

> Live site: [balaji-portfolio12.vercel.app](https://balaji-portfolio12.vercel.app)

A personal portfolio built to showcase my work in cybersecurity, penetration testing, OSINT, and full-stack development. Designed with a security-analyst aesthetic — slate-navy palette, terminal boot sequence, network-graph background, and project methodology writeups instead of generic descriptions.


## Tech Stack

- **React** — component-based UI
- **Tailwind CSS v4** — utility-first styling
- **Vite** — build tool and dev server
- **Vercel** — deployment and hosting



## Sections

- **Hero** — terminal boot sequence with typewriter animation + 3D tilt photo
- **About** — professional summary with animated stat counters
- **Experience** — internship timeline (Hackup Technologies)
- **Projects** — SecureSphere & Anti Wildlife Tracking with full methodology writeups (objective → method → finding → next)
- **Skills** — categorized tech arsenal (security tools, programming, web dev, DSA)
- **Certifications** — clickable image gallery with modal viewer (6 certs)
- **Hackathons** — 6 competitions and contests
- **Education** — Dr. NGP Institute of Technology
- **Contact** — terminal-style contact links



## Run Locally

```bash
# Clone the repo
git clone https://github.com/BALAJI-R02/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

Opens at `http://localhost:5173`

---

## Deploy

Deployed on Vercel. Every push to `main` triggers an automatic redeploy.

```bash
git add .
git commit -m "your message"
git push
```
